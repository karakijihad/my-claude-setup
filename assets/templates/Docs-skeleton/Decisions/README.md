# Decisions Index

Accepted decisions, one file per day. Newest date at the top. Several decisions in one day
share that day's file, newest timestamp first within it.

| Date | File | Titles |
|-|-|-|
| YYYY-MM-DD | [YYYY-MM-DD.md](./YYYY-MM-DD.md) | [titles of decisions recorded that day] |

Format per file: see the `decision-entry.md` template.

**Record the option you rejected.** The diff shows the road taken; nothing in git shows the
road refused, and that is what gets re-litigated later.

**An audit is not a decision.** Audits live in `../Audit/`. Accepted decisions live here.

*(Previously named `Doclog/`. If a project still uses that name, keep it — renaming an
append-only history buys nothing.)*
